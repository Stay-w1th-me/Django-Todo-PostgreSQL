# Django Todo PostgreSQL

Учебное веб-приложение для управления задачами, разработанное на Django с использованием PostgreSQL.

## Возможности

- регистрация пользователей через администратора;
- авторизация пользователей;
- создание задач;
- просмотр своих задач;
- редактирование задач;
- изменение статуса выполнения;
- удаление задач;
- разграничение доступа между пользователями;
- администрирование через Django Admin;
- хранение данных в PostgreSQL.

## Стек

- Python
- Django
- PostgreSQL
- psycopg
- python-dotenv
- HTML
- Git / GitHub

## Структура базы данных

Основные сущности:

- `auth_user` — пользователи;
- `tasks_task` — задачи.

Связь:

`auth_user (1) -> (M) tasks_task`

Каждая задача принадлежит одному пользователю.

## Безопасность

- авторизация через Django Authentication;
- CSRF-защита форм;
- пароли хранятся в хэшированном виде;
- параметры подключения к БД хранятся в `.env`;
- пользователь может работать только со своими задачами;
- приложение использует отдельного пользователя PostgreSQL `django_user`.

## SQL

В проекте используются:

- SELECT;
- JOIN;
- LEFT JOIN;
- GROUP BY;
- COUNT;
- FILTER;
- ORDER BY.

## Тестирование

Запуск тестов:

```bash
python manage.py test
```

Проверяются:

- отображение собственных задач;
- запрет просмотра чужих задач;
- изменение статуса задачи.

## Запуск проекта

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Создать файл `.env`:

```text
DB_NAME=django_todo_db
DB_USER=django_user
DB_PASSWORD=your_password
DB_HOST=127.0.0.1
DB_PORT=5432
```

Применить миграции:

```bash
python manage.py migrate
```

Запустить сервер:

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000/
```
